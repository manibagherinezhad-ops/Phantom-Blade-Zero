# ⚔️ Phantom Blade Zero

> A dark-themed, responsive interactive image gallery built with **HTML5, Tailwind CSS, and CSS animations**, featuring character cards, smooth hover effects, and an animated social media footer.

---

## 🖤 About The Project

**Phantom Blade Zero** is a front-end practice project created to explore **Tailwind CSS, responsive web design, CSS media queries, image positioning, hover interactions, gradient backgrounds, and CSS animations**.

The project features three character-inspired image cards arranged in a visually balanced layout.

Each card responds to hovering by removing its dark overlay and revealing the character's name through a smooth sliding animation.

The page also includes a cinematic footer with a custom background image and animated social media icons.

The layout is designed to adapt to different screen sizes using CSS media queries.

The main focus is on creating a visually engaging interface using **HTML and Tailwind CSS**, without relying on JavaScript for the interactions.

## ⚡ How It Works

The main section contains three image cards built using HTML `<figure>` elements.

Each card includes a character image, a semi-transparent dark overlay, and a caption positioned below the visible card area.

Tailwind CSS `group` and `group-hover` utilities control the hover interactions.

When the user hovers over a card:

- The dark overlay fades away.
- The character image becomes more visible.
- The caption slides upward into view.
- Smooth transitions create a more polished interaction.

The footer uses a custom background image with a gradient overlay to improve visual contrast.

Three social media icons are displayed with staggered CSS fade-up animations.

Hovering over each icon changes its color, moves it upward, increases its size, and adds an orange glow.

CSS media queries are used to adjust the layout for smaller screens.

All these visual interactions are implemented without JavaScript.

## 📱 Responsive Design

The project uses **CSS media queries (`@media`)** alongside Tailwind CSS to adjust the layout across different screen sizes.

The responsive styles target three main breakpoints:

| Device | Breakpoint | Layout Behavior |
|---|---|---|
| 🖥️ Desktop | Above 1024px | Original three-card layout with staggered positioning |
| 📱 Tablet | 768px – 1024px | Adjusted card dimensions, spacing, and section height |
| 📱 Mobile | 481px – 767px | Vertically stacked cards with adjusted spacing and footer dimensions |
| 📲 Small Mobile | Up to 480px | Compact cards, reduced footer height, and smaller social media icons |

The responsive implementation focuses on:

- Adapting card widths and heights
- Changing the Flexbox direction on mobile devices
- Adjusting section padding and spacing
- Removing staggered vertical offsets on mobile
- Resizing the footer for smaller screens
- Adjusting social media icon sizes

The goal is to maintain the project's dark visual identity while improving usability across different screen sizes.

## 🎨 Design Direction

**Phantom Blade Zero** follows a dark, cinematic design style inspired by action and fantasy aesthetics.

The interface combines deep purple and black gradients, large character imagery, rounded borders, and subtle animations.

The staggered positioning of the three cards creates movement and makes the desktop layout more visually interesting.

On smaller screens, the responsive layout is intended to prioritize vertical content flow and readability.

The footer continues the cinematic atmosphere through its background image, dark overlay, and glowing social media icons.

The result is a compact front-end experiment focused on **responsive layouts, visual presentation, hover interactions, and CSS-based motion**.
